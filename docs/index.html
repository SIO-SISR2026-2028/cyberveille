Connexion à votre dépôt (une seule fois)

Le site est hébergé gratuitement sans serveur : pour enregistrer vos réglages, il a besoin d'une clé d'accès limitée à ce dépôt uniquement. Elle reste dans ce navigateur, rien n'est envoyé ailleurs qu'à GitHub.

  1. Créer la clé sur GitHub
  2. Repository access → Only select repositories → cyberveille
  3. Permissions → Repository : Contents, Secrets et Actions → Read and write
  4. Expiration : au choix (ex. 1 an) → Generate token → copiez-la ci-dessous
